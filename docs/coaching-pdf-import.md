## Behavior

The importer supports structured admin PDFs generated by Nicole's skill: workout-only, meal-only or both. It validates selectable-text envelopes, SHA256, identity/revision, exact schema keys and field limits. It does not interpret arbitrary PDF layouts, client PDFs or scans. Files are read in the browser using a bundled PDF.js worker; only the checked envelope and chosen exercise matches are sent to the authenticated server action, where validation is repeated.

- Workouts become private drafts with explicit weeks/days, per-set reps/weight/rest/instructions, warm-up/working labels, supersets and notes. Library matches must be exact/unique or chosen explicitly. PDF exercise labels are retained.
- Meals become unassigned versions in the existing meal editor, including portions, fixed food lists OR complete pick-one meal alternatives, supplied nutrition values and client-facing schedule/meal notes. A meal cannot mix items and options, because the current client interface displays one mode at a time. Unknown nutrition remains null; zero remains explicit zero.
- Meal schedules are textual. This does not add automatic day/week rotation or redesign the meal builder. A macro-only document without meals is outside this contract; the skill asks Nicole for the meal structure rather than inventing foods.
- Combined creation is transactional. Repeated source ID/revision/checksum reopens existing work; different data under the same identity is rejected. A new revision creates a new reviewable plan, never overwrites a client's assignment.
- Coach notes have separate coach-only tables. Workout snapshots/client previews whitelist public fields. Meal notes are displayed on the admin version page and copied privately on assignment.
- Program and meal assignment copies are transactional, copy all version/prescription fields, and preserve history. Newly imported workout seed versions cannot be assigned through the old assignment picker; Nicole must first open/apply the draft.
- Existing unfinished workouts retain their original snapshot and set targets across updates. Editing an assigned program retains its original start date.
