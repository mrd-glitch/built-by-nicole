# NS social / event graphics kit

Four square (1:1) templates, drawn at 360px in the sheet and designed to scale to 1080×1080:

1. **Challenge announce** — Cinzel over `--grad-flyer`, the treatment used on the supplied Misogi flyers.
2. **Programme promo** — ink card, photo at 50% under a bottom scrim, Montserrat Black headline, mono spec line.
3. **Neon club title** — the Mom's Club treatment: Montserrat Black + Kaushan Script with `--glow-pink` / `--glow-yellow`.
4. **Quote card** — paper, 3px pink rule, display type, ring mark bottom-right.

`Templates.jsx` holds all four; each is a standalone function you can copy out.

**Not reproduced:** the female-athlete silhouette that appears on the original Misogi artwork. It is a
custom illustration and was supplied only as flattened raster art — see `assets/event-graphics/` for the
originals. Send the vector if you want it as a reusable element.
