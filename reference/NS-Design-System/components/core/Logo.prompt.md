Brand mark image wrapper — use wherever the NS identity appears (nav, footer, app header, slide corners).

```jsx
<Logo variant="lockup-on-ink" size={64} basePath="../../assets/logos" />
<Logo variant="swirl-pink-paper" size={28} />
```

Six supplied files: three lockups (with NS letters) and three ring-only marks. Set `basePath` to the relative path from your page to `assets/logos`. Do not recolour, rotate, or crop the mark; do not typeset "NS" yourself when a file will do.
