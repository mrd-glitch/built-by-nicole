Single-line stroke glyph (Lucide, 2px) — the substituted icon set for NS; use it anywhere an icon is needed instead of drawing SVG or reaching for emoji.

```jsx
<Icon name="dumbbell" size={24} />
<Icon name="arrow-right" size={18} color="var(--accent)" />
```

Load once per page: `<script src="https://code.iconify.design/iconify-icon/2.1.0/iconify-icon.min.js"></script>`. Icons inherit `currentColor`, so they take the parent's text colour by default.
