Uppercase status pill for state and metadata — "4 spots left", "Week 3", "Live".

```jsx
<Badge tone="accent">4 spots left</Badge>
<Badge tone="highlight">New</Badge>
<Badge tone="success" dot>Checked in</Badge>
```

Tones: `accent`, `highlight`, `ink`, `soft`, `neutral`, `success`, `outline`, `outline-invert`. Text only — no icons, keep it under three words.
